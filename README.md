'# AI in Additive Manufacturing

An educational platform for understanding and implementing AI in manufacturing and 3D printing.

## Overview

This repository houses an educational platform designed to bridge the domains of Additive Manufacturing (AM) and Artificial Intelligence (AI). The platform serves as a comprehensive resource for AM professionals, researchers, engineers, and educators looking to leverage the power of AI technologies, including generative AI, in their manufacturing workflows.

## Main Sections

- **Introduction to AI in AM** - Foundational concepts and terminology
- **Develop AI Models for AM** - Step-by-step implementation guides
- **AI Agents in AM** - Applications of autonomous AI systems
- **Resource Repository** - Datasets, tools, and learning materials
- **Miscellaneous Projects** - Additional research and applications

## Features

- Responsive design for all devices
- Integrated search functionality
- Content depth indicators (beginner/intermediate/advanced)
- Structured learning paths
- Interactive navigation with breadcrumbs and table of contents

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/AI_in_AM.github.io.git
   cd AI_in_AM.github.io
   ```

2. View the site locally:
   - Open `index.html` in your browser
   - Or use a local server: `python -m http.server`
